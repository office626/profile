## どのお立場の方ですか？

- **自治体・行政の方** — 計画策定、審議会・委員、庁内ワークショップ。オンライン参加可。年間の出席可能回数はご相談ください。
- **中小企業の経営者の方** — まずは無料相談の入り口から。経営改善計画・生産性向上・AI導入を、会津・関東を中心に伴走します。
- **大企業の方** — 自治体との共創・実証のコーディネート。NEC退職済みで、特定ベンダーとの専属関係はありません。
- **NPO・地域活動の方** — 予算が限られる活動向けに、無償・減額の相談枠を設けています。合意形成の場づくりも対応します。
- **研修・講演の主催者の方** — 90分〜半日の演題を多数用意。司会・モデレートも承ります。

## まずは無料・低額で相談できる入り口があります

中小企業の経営者の方は、次の制度を入口にご利用いただけます。どれが使えるかは、短いヒアリングで整理します。

- **よろず支援拠点 生産性向上支援センター** — 福島県内の中小企業向け。初回相談は無料。現場の生産性向上・業務改善を伴走支援。
- **経営革新等認定支援機関** — 経営改善計画の策定支援。補助金・制度活用の要件整理に対応。
- **中小機構 中小企業アドバイザー／信用保証協会・中央会 専門家** — 派遣・紹介経由の支援。事業者負担が軽減されるケースがあります。

## お任せいただけること

### 自治体の計画づくりと政策立案の伴走

総合計画・産業振興計画・DX推進計画の策定支援、審議会・有識者委員、庁内ワークショップの設計と進行。国の政策側で計画を書いた経験を活かし、上位計画や交付金の要件と現場のやりたいことを無理なく接続します。オンライン参加可。契約形態は委員報酬・謝金・業務委託など、実績のある形態に対応します。

　経験：内閣府での科学技術・イノベーション基本計画策定／総合計画審議委員・自治体アドバイザー多数

### 中小企業の経営改善計画・数値計画の策定と実行支援

決算書の分析から、金融機関に提出できる経営改善計画・資金繰り表・数値計画までを作成し、月次モニタリングまで伴走します。製造・卸売・サービスなど従業員5〜50名規模の支援実績があります。標準的には月1回訪問・6か月程度の伴走です。

　経験：中小企業診断士／経営革新等認定支援機関／よろず支援拠点サポーター

### 生産性向上・業務改革の現場支援

時間観測に基づく現場の可視化から、改善計画づくりまで。大企業で実行した間接部門改革・稟議システム導入の経験を、中小企業の規模に合わせて置き換えます。

　経験：福島県よろず支援拠点 生産性向上支援センター サポーター／NEC コーポレート変革

### AI・ICT活用の導入支援（構想から実物まで）

勉強会で終わらせず、業務で動くものを一緒に作るところまで。生成AIの業務適用、社内ルール整備、小さな内製ツールの試作に対応します。

　経験：JDLA Deep Learning for GENERAL 合格／総務省 財務・会計DXアドバイザー

### 研修・講演・ワークショップの設計と登壇

経営指導員・自治体職員・経営者向けに、演習と持ち帰り成果物まで含めて設計。司会進行、パネルモデレート、イベント全体の企画運営も承ります。

　経験：エフエム会津 パーソナリティ／デジタル庁 well-being指標活用ファシリテーター

### 地域診断・産地／商店街の面的支援

統計の読み解き、地域経済循環の整理、キーパーソン洗い出し、使える国の政策との接続までを一つのレポートにまとめます。

　経験：地域診断・面的支援（2018年〜）／NPO 中小企業・地域創生ネットワーク 理事

### 大企業と自治体をつなぐ共創・実証のコーディネート

双方の意思決定の作法の違いを踏まえて話をまとめます。予算サイクルや稟議の実務感覚も共有できます。守秘契約の締結に対応します。

　経験：スマートシティ社会実装コンソーシアム（のべ約300団体）／千葉県DX推進協議会

### 成長企業のコーポレート機能・グループ経営の設計

会議体・決裁ルール・ガバナンス、理念の言語化と浸透。大企業の型をそのまま持ち込まず、規模に合った最小構成に落とします。

　経験：NEC 経営企画部門でのグループ経営（約400社）
